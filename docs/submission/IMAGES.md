## Capture guidance

- 1440px-wide viewport or 1920×1080 at 100% zoom; keep mainnet and timestamps visible.
- Show an actual green verification PASS only if the receipt and required
  artifacts independently pass. Otherwise use explorer proof or the honest
  incomplete result. Do not edit statuses.
- Label every local/recorded swap. It does not replace mainnet proof.
- Re-capture if agent, balances or mandate change. Images are dated observations.
