# Live dashboard demo connection

The browser uses the same-origin GET-only `/api/agent?path=/feed/...` relay. The relay permits only existing public feed routes and content-addressed artifacts, has a fixed operator-selected upstream, forwards no cookies/credentials, and never loads the keeper's environment or signing key. Mutations, arbitrary URLs, paths and cursors fail closed. Short server-side caching coalesces repeated judge reads.

The owner-approved demo now uses `http://129.159.17.90:8788`: no domain and no Cloudflare. The browser-to-Vercel connection remains HTTPS; Vercel-to-VM traffic, including its dedicated disposable relay credential, is unencrypted. Do not use this setup for private data or wallet keys. Replace it with HTTPS for a permanent installation and rotate the relay token after judging.

Set `AGENT_FEED_UPSTREAM` to override the demo endpoint in `apps/dashboard/server/demo-feed.ts`. Set `AGENT_FEED_PROXY_TOKEN` only in the Vercel server environment and the ignored local server environment. No key belongs in `VITE_*`. Omit `VITE_AGENT_FEED_URL` to use the same-origin relay. The relay sends only the operator token to the VM; it never forwards browser credentials.

The separate `nalvis-feed-proxy.service` runs `scripts/oci-feed-proxy.py` on TCP 8788. It reads its dedicated token from `/srv/nalvis/feed-proxy.env` (root-readable, mode 600). Its fixed upstream is the unchanged keeper at `127.0.0.1:8787`. Anonymous requests are 401, mutations are 405, and forbidden paths/queries are 400. No signing, key-management, trade or configuration route is exposed. OCI security-list ingress and the VM firewall allow only the additional TCP 8788 port, with an any-IPv4 source because the current Vercel setup has no fixed egress IP. The proxy enforces authentication. Both services run on OCI while the PC is off. After validating replacement access, disable the old Cloudflare service with `sudo systemctl disable --now nalvis-feed-tunnel.service`. After judging, close TCP 8788, stop the proxy and remove/rotate its Vercel secret.
